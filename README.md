# 🎓 Student Management System

A CLI-based Student Management System built with Python using OOP concepts.

## Features
- ✅ Add / Update / Delete / List students
- ✅ Unique ID validation
- ✅ Persistent storage (JSON file)
- ✅ Formatted console output
- ✅ OOP with Student & StudentManager classes

## How to Run
```bash
python main.py
```

## Project Structure
| File | Purpose |
|------|---------|
| `student.py` | Student class (model) |
| `manager.py` | CRUD + file I/O logic |
| `main.py` | CLI menu interface |
| `students.json` | Auto-generated data file |
